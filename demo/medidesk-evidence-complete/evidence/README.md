# MediDesk Capstone Evidence

This folder combines the previously curated evidence screenshots with the additional screenshots from `docs.zip`. Exact byte-for-byte duplicate screenshots were removed; the curated, descriptive filenames were retained as the canonical copies. Similar-looking screenshots with different contents were kept.

## Curated evidence

- `01-github-actions-workflow-history.png` — GitHub Actions workflow history.
- `02-prometheus-http-request-metrics.png` — Prometheus HTTP request metrics.
- `03-prometheus-targets-backend-grafana-up.png` — Prometheus targets for backend and Grafana.
- `04-prometheus-up-query.png` — Prometheus `up` query.
- `05-helm-release-and-monitoring-pods.png` — Helm release and monitoring pods.
- `06-frontend-ingress-http-200.png` — frontend ingress HTTP 200 response.

## Additional screenshots

`additional-screenshots/` contains the other unique screenshots from the uploaded archive, retaining their original timestamp-based filenames. These include terminal command output, application/deployment views, CI screens, and monitoring/dashboard screens. Filenames are preserved to avoid claiming more detail than can be verified from the screenshot alone.

## Deduplication

Exact file duplicates were removed across both archives. The six curated screenshots above were also present in the uploaded `docs.zip`, so the curated copies were kept and the duplicate copies were omitted. Distinct screenshots were not removed just because they looked similar.

Review the additional screenshots and choose the strongest evidence required by the capstone rubric. Confirm that the final repository includes required test results, CI/security scan results, Terraform/AWS state, Kubernetes/Helm/Ingress, Prometheus targets, and a populated Grafana dashboard if these are rubric requirements.
